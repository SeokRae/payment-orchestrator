# 결제 서비스 규제 준수 체크리스트 (5개 도메인)

> **이 체크리스트는 실무 조기 신호 포착용이며 법률 자문을 대체하지 않는다.** 웹 검색·공식 사이트(금융위·금감원·개인정보위·PCI SSC·KOFIU 등)를 종합한 리서치 결과로, 세부 수치·조문 해석·자사 사업모델 해당 여부는 반드시 금융위/금감원/개인정보위 질의 또는 법무법인 검토로 재확인해야 한다. **확인 상태** 열의 표기 기준:
> - ✅ **확인됨** — 공식 출처(법령정보센터·정부기관 공식 사이트)로 직접 대조된 항목 (그래도 최신 개정 여부는 별도 확인 권장)
> - ⚠️ **부분확인** — 2차 출처(로펌 뉴스레터·언론보도·업계 블로그) 기반이거나 세부 기준이 출처마다 갈리는 항목 — 법무 확인 권장
> - ❓ **미확인** — 원문 대조를 하지 못했거나 당국의 최종 유권해석이 없는 항목 — 법무 확인 필수, 이 표기만으로 "해당 없음"이라 단정하지 말 것
>
> 법정 수치(자본금·처리기간·과태료·시행일 등)는 리서치 시점(2026-08-01) 기준이며 개정 여지가 있다. 리서치 상세 근거·출처 URL은 각 도메인 리서치 원본(오케스트레이터 실행 로그) 참조.

## 도메인 2 — PCI-DSS (카드정보 PAN 저장/처리/전송)

| 항목 | 트리거 조건 | 필요 조치 | 리스크 | 확인 상태 |

## 도메인 선별 가이드 (서비스 특성 → 해당 도메인)

| 서비스 특성 | 해당 도메인 |
|------------|------------|
| 국내 카드/계좌 기반 결제, 정산 관여 있음 | 도메인 1(전자금융거래법) 필수 |
| 개인정보(카드정보·거래내역 등)를 처리 — 사실상 모든 결제 서비스 | 도메인 3(개인정보보호법) 필수 |
| 카드번호(PAN)를 자사가 직접 저장/처리/전송 | 도메인 2(PCI-DSS) 필수 |
| 카드정보를 결제창 위탁(TPSP 리디렉션/iframe)만 처리 | 도메인 2 필수(SAQ A/A-EP 범위로 축소) |
| 가상자산·스테이블코인 취급 | 도메인 4(특금법 AML/VASP) 필수 |
| 가상자산·스테이블코인 미취급 | 도메인 4는 "해당 없음"으로 처리(판단 근거 기록, 서비스 확장 시 재검토 필요) |
| 해외 PSP(Stripe 등)·해외 카드사와 직접 연동, 정산금 국경간 이동 | 도메인 5(외국환거래법·GDPR) 필수 |
| 해외 PSP·카드사 직접 연동 없음 | 도메인 5는 "해당 없음"으로 처리(판단 근거 기록, 서비스 확장 시 재검토 필요) |
| EU 거주자 대상 서비스 또는 EU 결제수단 지원 | 도메인 5 중 GDPR 하위 항목 필수 |
